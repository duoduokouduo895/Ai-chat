# AI-chat 监控与性能手册

## 健康检查

[FACT-MON-001] `/actuator/health` 用于查看服务健康状态。执行压测或效果评测前后都应采集健康快照。

[FACT-MON-002] 性能压测与 RAG 效果评测解决的问题不同：性能压测关注 TPS、P95 和错误率；效果评测关注召回、拒答和回答可信度。

[FACT-MON-003] RAG 生成链路需要单独记录 TTFT 和完整耗时。TTFT 表示从发送请求到收到首条有效回答片段的时间。

[FACT-MON-004] 外部模型或 Embedding API 的延迟会影响结果，因此报告必须将应用自身错误和外部供应商错误区分记录。
